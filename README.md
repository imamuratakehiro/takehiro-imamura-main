# Portfolio

Personal portfolio website showcasing skills, experience, publications, and awards.

## GitHub Pages Setup

This portfolio is designed to work with GitHub Pages. To deploy:

1. Push this repository to GitHub
2. Go to your repository settings
3. Navigate to **Pages** section
4. Under **Source**, select:
   - Branch: `main`
   - Folder: `/ (root)`
5. Click **Save**

Your portfolio will be available at: `https://[your-username].github.io/[repository-name]/`

## Customization

Edit [index.html](index.html) to update your information:

- **Name and Position**: Update in the hero section
- **Social Links**: Update URLs in the social-links section
  - X (Twitter)
  - Instagram
  - LinkedIn
  - GitHub
  - Email
- **About**: Add your introduction
- **Skills**: Update programming languages, spoken languages, certifications, and research interests
- **Education**: Add your academic background
- **Experience**: Add your work history
- **Publications**: Add your papers (journal, conference, thesis)
- **Awards**: Add your achievements

## Local Development

Simply open [index.html](index.html) in a web browser to preview locally.
